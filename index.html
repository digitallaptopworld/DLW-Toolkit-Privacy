DLW Toolkit – Privacy Policy

Effective date: November 22, 2026

Digital Laptop World ("DLW", "we", "our") respects your privacy. This Privacy Policy explains how DLW Toolkit handles information when you use the application.

1. Information Accessed by the App

DLW Toolkit displays system information and device status. Depending on the feature used, it may access information such as:

  • Computer name and Windows system information.
  • Processor, memory and storage information.
  • Network adapter details, including IP and MAC addresses.
  • System performance information.

This information is used locally to display the requested information inside the application. The app does not intentionally upload these displayed system details to our servers.

2. Internet Connection and Updates

DLW Toolkit connects to GitHub to check for available software updates and download update files when requested.

These requests may expose standard connection information, such as your IP address, to GitHub. GitHub handles this information according to its own privacy policy.

3. Data Collection and Analytics

DLW Toolkit does not include user account registration, advertising trackers, or built-in analytics and telemetry. It does not intentionally collect or transmit the system information displayed by the app.

4. Data Sharing

We do not sell or rent users' personal information. The app does not intentionally share locally displayed system information with third parties.

5. Data Security

We recommend keeping the application updated and using a supported version of Windows. Internet communication for update checks is handled through GitHub services.

6. Children's Privacy

DLW Toolkit is a general-purpose Windows utility. It is not designed to collect personal information from children.

7. Changes to This Policy

We may update this Privacy Policy when application features or practices change. Any updated version will be published on this page.
